# ManifoldANN.jl

Experimental Julia package for approximate nearest neighbours (ANN) on manifolds. Currently just a scaffold with a basic test harness.

## Developing

```bash
make test
```

## Directory Layout

- `src/` package source
- `tests/unit/` unit tests, loaded via `test/runtests.jl`
- `docs/examples/` documentation assets and examples (placeholder)
- docs/design/ documetns design decisions taken
